# P1 Prompts

## Prompt 1

Following `skills/prolog-dev/SKILL.md`, start `code/82_q1.pl`.
Define ONLY the helper predicates (if needed) and `clue(N, Solution)` for N = 1..8.
A `Solution` is `[p('Alex', D1, L1, P1), p('Ben', D2, L2, P2), p('Carla', D3, L3, P3), p('Dana', D4, L4, P4)]`.
Exact atoms:
- Dept: `research`, `development`, `design`, `testing`
- Lang: `python`, `java`, `'c++'`, `javascript`
- Project: `'AI'`, `web`, `embedded`, `data`
Clues:
1. Friend who prefers `'AI'` does not work in `research` and is not `'Dana'`.
2. `'Alex'` does not work in `development` and does not prefer `'c++'`.
3. Friend in `testing` likes `python`.
4. `'Ben'` prefers `web` and does not work in `testing`.
5. Friend whose favorite language is `java` works in `design`.
6. `'Carla'`'s project is not `embedded`, and her department is not `development`.
7. `'Dana'`'s favorite language is not `java`, and she works in `research` or `testing`.
8. Friend who prefers `data` works in `research` and does not use `javascript`.
Use `memberchk/2` instead of `member/2` inside `clue/2` (since `Solution` is already fully instantiated, `member/2` can leave extra choicepoints that cause `count_solutions/2` to overcount).
Verify with `swipl` that there are no syntax or singleton warnings.

## Prompt 2

Then add `main/0` using `once(solve([1,2,3,4,5,6,7,8], Solution))` to print strictly one solution as four lines in order Alex, Ben, Carla, Dana:
Alex = [Dept, Lang, Project]
Ben = [Dept, Lang, Project]
Carla = [Dept, Lang, Project]
Dana = [Dept, Lang, Project]
Use `format('~w = [~w, ~w, ~w]~n', [Name, Dept, Lang, Project])` so there are spaces after commas (e.g., `Alex = [research, python, AI]`), because SWI-Prolog's `~w` on a list omits spaces.
No `:- initialization(main)` and no `halt/0`. Test with `swipl -q -f code/82_q1.pl -g main -t halt`.
